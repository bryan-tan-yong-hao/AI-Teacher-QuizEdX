# AI Teacher Persona Quiz

A simple static quiz website that can be hosted on GitHub Pages.

## Files
- `index.html`
- `style.css`
- `script.js`

## How to publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload these 3 files to the repository root.
3. Go to **Settings** > **Pages**.
4. Under **Build and deployment**, choose:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Save.
6. Wait about 1–3 minutes.
7. Your site will appear at:
   `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/`

## Customising content
- Edit questions in `script.js` under `quizData`
- Edit persona names and results in `script.js` under `personaResults`
- Edit colours and styling in `style.css`
